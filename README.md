# 《知识整理》

## 从资料堆到可复用知识系统

**读者承诺**：帮助知识工作者、独立研究者、作者和学习者，把一个具体主题从零散资料整理成可追溯、能回答问题、可供行动与复用的知识系统；不承诺靠某个软件或笔记法自动产出原创成果。
